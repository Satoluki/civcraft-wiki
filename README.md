# Личная вики CivCraft Cristalix

Сайт: https://satoluki.github.io/civcraft-wiki/

Неофициальный справочник по текущему Cristalix: 132 статьи, 73 здания, 22 чуда и 107 технологий. Объяснения написаны простым языком; исторические справки VimeWorld раскрываются отдельно внизу статей.

Снимок источников: 25 ноября 2026. Расхождения между карточками и обновлением сезона отмечены явно; игровой проверки значений не было. Автоматической синхронизации с игровым сервером нет.

Данные и оригинальные иконки: https://civcraft-wiki.cristalix.gg/
Структура вдохновлена https://civ-wiki.vimeworld.com/
Графика принадлежит её авторам. Это личный справочник, не официальный сайт проектов.

## Размещение

GitHub Pages публикует статические файлы из корня ветки main. Сборка и внешний сервер не требуются. После изменения файлов и push сайт обновляется через Pages.

Избранное и личные заметки хранятся только в браузере. Для переноса между адресами и устройствами используй экспорт и импорт в разделе «О личной вики».

Локальные исходные материалы и инструменты сборки находятся в соседнем проекте civcraft-wiki; исследовательские снимки и данные пользователя в этот публичный репозиторий не включены.
